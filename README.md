# ТИШЕ — сайт кофейни

Готовая демонстрационная версия для GitHub Pages. Включены последние правки: кликабельное поле даты, заглушки отзывов и расположения, векторные иконки для телефонов и компьютеров.

## Публикация через браузер

1. Распакуйте архив на компьютере: в Windows нажмите правой кнопкой по ZIP → «Извлечь всё».
2. Создайте на GitHub новый публичный репозиторий, например `tishe-coffee`. При создании можно включить добавление README, чтобы сразу появилась ветка `main`.
3. Откройте репозиторий → `Add file` → `Upload files`.
4. В распакованной папке выделите всё содержимое и перетащите его в окно загрузки. Сам ZIP и внешнюю папку загружать не нужно. Файл `index.html` должен оказаться сразу в корне репозитория, рядом с `app.js`, `styles.css` и папкой `assets`.
5. Дождитесь загрузки. Внизу страницы сохраните изменения в `main` (при наличии выбора — `Commit directly to the main branch`). Если выбрано создание новой ветки, завершите и объедините pull request, чтобы файлы оказались в `main`.
6. Откройте `Settings` → `Pages`. В разделе `Build and deployment` выберите `Source: Deploy from a branch`, затем ветку `main` и папку `/(root)`. Нажмите `Save`.
7. Дождитесь завершения публикации. Ссылка на сайт появится на странице `Settings` → `Pages`. Состояние публикации можно посмотреть во вкладке `Actions`.

Для отдельного репозитория адрес обычно выглядит так:
`https://ВАШ-ЛОГИН.github.io/tishe-coffee/`

Если сайт показывает 404, убедитесь, что публикация завершена и `index.html` находится именно в выбранной папке `/(root)` ветки `main`.
Если вы видите только описание проекта, проверьте, что файлы не оказались внутри дополнительной папки.

## Что внутри

- `index.html` — страница сайта.
- `styles.css` — оформление и адаптивность.
- `app.js` — меню, корзина, демонстрация бронирования и анимации.
- `assets/` — фотографии, шрифты и значок сайта.

Сборка, Node.js и установка библиотек не нужны. Все изображения и шрифты включены в архив. Относительные пути позволяют размещать сайт в отдельном репозитории GitHub Pages.

## Демонстрационный режим

Кофейня вымышленная. Меню, цены и время визита показаны для примера. Отзывы, карта и адрес — заглушки. Настоящие брони не создаются, оплата не принимается, введённые данные никуда не отправляются. Выбранные позиции хранятся только до обновления страницы.

## Обновления сайта

Измените нужные файлы, загрузите их на место прежних в ту же ветку `main` и сохраните изменения. GitHub Pages опубликует обновлённую версию.
